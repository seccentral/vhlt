# Codebase Audit — Claude Opus 5.5 (2026-11-10 11:57)

**Scope:** Static, read-only review of all sources in `common/`, `template/`, `hlcsg/`, `hlbsp/`, `hlvis/`, `hlrad/`, `ripent/`, plus build, CI, docs and repo hygiene. The review was split across six parallel reviewers by subsystem. Each one was asked to (1) check the "Fixed" claims in `audits/2026-11-10/handling.md` and (2) find defects that audit missed. One scratch MinGW 64-bit Release build and one Doxygen run were done outside the repo. No repository files were changed by the review.

**Method notes:**
- Findings come from reading code with the default build macros (`common/cmdlib.h`) applied, so code compiled out by `#ifdef` is labelled **dead**.
- Tags: **NEW** (not in the prior audit), **INCOMPLETE** (a prior fix is partial or misses the live code path), **REGRESSION** (a prior fix introduced a new problem).
- "Plausible" means the reasoning holds but the failure was not traced end to end.

### Low

**Behaviour and logic:**
- **`-threads` has no effect in hlbsp.** A local declaration hides the global (`hlbsp/qbsp.cpp:1918`).
- **The `hullfile` key never takes effect in hlcsg.** It is applied after `LoadHullfile` has run. `ValueForKey` is never NULL, so its `if` is always true (`hlcsg/qcsg.cpp:166-169`).
- **The `smooth` key is ignored.** It is read into `flTmp`, but the threshold uses `g_smoothing_value` (`hlrad/qrad.cpp:386-390`).
- **`IPlaneEquiv` never checks reversed normals.** Its second loop copy-pastes the first (`hlcsg/brush.cpp:986-996`).
- **Wrong checksum length.** The texture checksum uses `g_numedges` instead of `g_texdatasize` (`common/bspfile.cpp:521`).
- **`MaxDistVis` uses `&&` where it should use `||`.** The result is NaN centres and a wasted fast path (`hlvis/flow.cpp:1581-1587`).
- **Dead-code copy-paste bug.** `p2` is used where `p1` should be (`hlrad/mathutil.cpp:519`).
- **`-inc` reruns drop `light_shadow` bounce styles.** A successful `readtransfers` skips `CreateFinalStyleArrays` (`hlrad/vismatrix.cpp:661`, `hlrad/sparse.cpp:941`).
- **hlbsp/hlvis count mismatch (plausible).** hlbsp counts NULL-winding portals but does not write them, so hlvis rejects the `.prt` (`hlbsp/portals.cpp:192, 292-301`).

**Bounds (writes before checks, off-by-one):**
- **Writes before the limit check:** `hlbsp/writebsp.cpp:381-382` (`g_dmarksurfaces`) and `hlbsp/surfaces.cpp:397-405` (`hvertex`).
- **Off-by-one and missing validation in `ReadSurfs`/`ReadBrushes`:** off-by-one checks, no rejection of negatives, unvalidated `planenum`, and `%u` read into `int` (`hlbsp/qbsp.cpp:1160, 1164, 1269, 1280`).
- **`mightsee` is 4095 bytes, but `g_bitbytes` can be 4096.** That is a one-byte overrun (`hlvis/vis.h:117`, `hlvis/flow.cpp:459, 624`).
- **Divide by zero when `g_portalleafs == 0`** (`hlvis/vis.cpp:818, 1059`).
- **Token parsing:**
  - `*script_p` is read before the `end_p` check (`common/scriplib.cpp:163-245`).
  - A token of exactly `MAXTOKEN` writes `g_token[MAXTOKEN]`.
- **Unpadded texture names.** `safe_strncpy` does not zero-pad, so names `+`/`-` leave `name[2..15]` uninitialized (`hlcsg/textures.cpp:697-715`).
- **`AddLump` reads up to 3 bytes past its source** (`common/bspfile.cpp:540`).
- **Overlapping `strncpy`.** `DefaultTexture(tex, tex->name)` uses the same source and destination (`hlrad/loadtextures.cpp:234, 343`; -Wrestrict).
- **No upper-bound check before the `.vis` read.** `wadconfigname[MAX_WAD_CFG_NAME] = 0` writes one past the end (dead code; `hlcsg/qcsg.cpp:2386`).

**Robustness and resources:**
- **Unchecked `fopen`** after `q_exists` (`hlcsg/hullfile.cpp:43-48`).
- **Unchecked `malloc`/`calloc`** at `hlrad/lightmap.cpp:6175`, `hlrad/qrad.cpp:1408, 1451, 1487, 1550` and `hlrad/trace.cpp:747, 774-776`.
- **Leaks:**
  - `tRGBData` on the `FailedRead` path (`hlrad/transfers.cpp:220-233`).
  - `dl->sunnormals`/`sunnormalweights` (`hlrad/lightmap.cpp:3444-3484`).
  - The Xash `*_direction` arrays (`hlrad/lightmap.cpp:7539`).
- **Dangling stack pointers.** `texlight.filename` holds stack pointers (latent; `hlrad/qrad.cpp:625`).
- **Unchecked options:**
  - `-texdata`/`-lightdata` compute `atoi()*1024` with no range check (`hlcsg/qcsg.cpp:2474`, `ripent/ripent.cpp:1063, 1079`).
  - `sysctlbyname`'s return value is ignored (`common/threads.cpp:584-588`).
- **ripent file handling:**
  - Without `-textureparse` it still deletes `<map>.tex` (`:528`).
  - It deletes the old `.ent` before parsing (`:779`).
  - `malloc(0)` raises a false out-of-memory error (`:546, :786`).
  - `strlen`/`strcasecmp` run on names that may not be NUL-terminated (`:622, :728`).
- **Undefined behaviour and races:**
  - In `vector_compress`, a shift of 32 or more is undefined (`hlrad/compress.h:195-197`), and this is the default rgb-transfer compression.
  - `HANDLE` is printed with `%08X` (`common/threads.cpp:461, 472`).
  - `(int)b1 << 24` overflows a signed int (`common/cmdlib.cpp:447, 504`).
  - `scriplib.cpp:294` passes a `char` to `%s`.
  - `stylewarningcount` is updated without a lock, and `rand()` is called in threaded `FinalLightFace` (`hlrad/lightmap.cpp:5028, 5162, 7300, 9062`).
- **Deep recursion (plausible).** `SimpleFlood`/`RecursiveLeafFlow` recurse deeply on threads with the default 1 MB Windows stack (`hlvis/flow.cpp:374, 644`, `common/threads.cpp:417`).
- **Big-endian hosts:** WAD `lumpinfo.size` is never swapped and the `.wa_` file is written in host order (`hlcsg/textures.cpp:419-444, 932-971`).
